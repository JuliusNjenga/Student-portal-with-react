# FULL-STACK STUDENT PORTAL
A full stack web application used to mimic a student portal.
## FEATURES
* Existing users can login with data that is on database only.
* Passwords are hashed using bcrypt to protect user and their privacy.
* Able to register new student and add to Database.
* Student logged in all there details are posted, like fees and courses.
* Protective route to prevent users from navigating to other pages with no validation.
* Neumorphism effect on the UI.
## Tech stack
* React.js and CSS for the front end.
* Node.js and Express.js for the backend.
* Postgres for the databases to sore data.
